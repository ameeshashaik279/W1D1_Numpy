\# Week 5 - Local LLM and PDF Q\&A Bot



\## Overview

This project runs Large Language Models locally using Ollama and builds a PDF Question Answering Bot using ChromaDB and Retrieval-Augmented Generation (RAG).



\## Tools and Technologies

\- Python

\- Ollama

\- Llama 3.2

\- Qwen 2.5

\- ChromaDB

\- Nomic Embeddings

\- PyPDF



\## Tasks Completed

1\. Installed and tested Ollama.

2\. Ran Llama 3.2 and Qwen 2.5 locally.

3\. Tested prompts and compared both models.

4\. Created a ChromaDB collection with 20 sample documents.

5\. Implemented similarity search and metadata filtering.

6\. Extracted text from a PDF.

7\. Built a PDF-based Q\&A bot using Ollama and ChromaDB.
