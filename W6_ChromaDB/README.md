# W6D4 - RAG Pipeline using LangChain and ChromaDB

## Objective
Build a Retrieval Augmented Generation (RAG) pipeline using ChromaDB and Ollama.

## Tasks Completed
1. Created a ChromaDB vector store.
2. Added 20 sample documents.
3. Generated embeddings using Ollama (nomic-embed-text).
4. Performed cosine similarity search.
5. Applied metadata filtering.
6. Extracted PDF text using pypdf.
7. Split PDF text into chunks.
8. Stored PDF chunks in ChromaDB.
9. Retrieved relevant chunks for a question.
10. Generated an answer using Ollama.

## Technologies
- Python 3.12
- ChromaDB
- LangChain Ollama
- Ollama
- pypdf
